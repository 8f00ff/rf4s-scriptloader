# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-bi] - 2025-06-13

### Added

- Experimental reimplementation of the "Everyone is Bi" mod
- Standalone patch logic enabling same-gender relationships
- Reference to the Nexus Mods [page](https://www.nexusmods.com/runefactory4special/mods/98) for original and future releases.

### Changed

- Documentation to clarify this branch is a standalone mod and is not the modloader itself.

## [0.1.0] - 2025-06-13

### Added

- MinHook integration
- Initial DLL proxy injection scaffold using SDL2.dll override
- Documentation:
  - Contributing guidelines
  - Attribution requirements
- Initial project structure
